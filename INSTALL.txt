========================================================================
FossilSoloMCP v1.0.1 - Fast Installation & Quick Start Guide
========================================================================

FossilSoloMCP is a Model Context Protocol (MCP) server providing 31
dedicated tools for Fossil SCM repositories.

Prerequisites:
  - Fossil SCM binary in system PATH (https://fossil-scm.org/)
  - Python 3.10+ or uv (https://astral.sh/uv)

------------------------------------------------------------------------
Quick Documentation:
------------------------------------------------------------------------
  - Double-click MANUAL.html for the interactive bilingual manual
    (Dark/Light mode, Romanian / English switch, full tool index).
  - Check README.md (English) or doc/citeste-ma.md (Romanian) for
    complete overview and configuration examples.

------------------------------------------------------------------------
Option A: Run Instantly with uvx (Zero-Install, Recommended)
------------------------------------------------------------------------
Add the server directly to your client configuration (Claude Desktop,
Cursor, Antigravity IDE mcp_config.json) without manually cloning code:

{
  "mcpServers": {
    "fossil-scm": {
      "command": "uvx",
      "args": ["fossil-scm-mcp"]
    }
  }
}

------------------------------------------------------------------------
Option B: Run from Local Directory with uv
------------------------------------------------------------------------
If running from a cloned repository or extracted folder:

{
  "mcpServers": {
    "fossil-scm": {
      "command": "uv",
      "args": ["run", "--directory", "C:/path/to/FossilSoloMCP", "fossil-scm-mcp"]
    }
  }
}

------------------------------------------------------------------------
Option C: Install from Wheel (.whl) or PyPI
------------------------------------------------------------------------
Run in your terminal or virtual environment:

  pip install fossil_scm_mcp-1.0.1-py3-none-any.whl

Or from PyPI:

  pip install fossil-scm-mcp

Then configure your client:

{
  "mcpServers": {
    "fossil-scm": {
      "command": "fossil-scm-mcp"
    }
  }
}
